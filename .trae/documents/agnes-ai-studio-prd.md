## 1. 产品概述

Agnes AI Studio 是一款面向创作者、设计师、运营人员和内容团队的多模态 AI 创作控制台。产品整合文本对话、AI 生图、AI 生视频、任务队列管理、作品预览与版本管理、素材模板资产沉淀等能力，让用户在一个界面内完成"想法 → 生成 → 预览 → 调整 → 导出"的完整创作闭环。

- 核心价值：将分散的 AI 能力组织成高效、可追溯、可复用的创作工作流
- 目标用户：内容创作者、设计师、运营人员、AI 爱好者、团队用户

## 4. 用户界面设计

### 4.1 设计风格

- **主色**：主紫 `#7C5CFF`、辅蓝 `#4DA3FF`、高亮青 `#00D4FF`，渐变 `linear-gradient(135deg, #7C5CFF, #00D4FF)`
- **背景色**：页面背景 `#0B0F1A`、次级背景 `#101523`、卡片背景 `#121827` / `#151B2D`
- **按钮风格**：主按钮紫蓝渐变 + 微弱发光 hover，次按钮玻璃拟态边框，文本按钮无背景
- **字体**：中文 PingFang SC / HarmonyOS Sans，英文 Inter / SF Pro Display
- **布局**：三栏固定布局，左 320px / 中自适应 / 右 280px，顶部栏 56px
- **图标**：线性图标（Lucide），线宽一致，配合文字标签
- **圆角**：卡片 12-16px，按钮 10-14px，输入框 10-12px
- **玻璃拟态**：顶栏、浮层、侧边工具面板使用 `backdrop-filter: blur(20px)` + 半透明背景

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 工作台 | 顶部栏 | 深色玻璃拟态背景、Logo 紫蓝渐变、模型选择器下拉、模式切换 Tab 高亮、API 状态圆点、算力进度条、用户头像 |
| 工作台 | 左侧控制区 | 深色卡片背景、模式 Tab 横向排列、提示词文本域带字数统计、参数组折叠面板、滑块实时数值、参考图网格、底部固定生成按钮渐变发光 |
| 工作台 | 中间预览区 | 深色背景、任务状态进度条、大图/视频播放器居中、工具栏图标按钮、版本缩略图横向滚动、任务日志折叠面板 |
| 工作台 | 右侧资产区 | 深色卡片列表、缩略图网格、标签筛选 Chip、存储空间进度条、空状态引导插图 |
| 设置 | 模型配置 | 表格列表 + 侧边抽屉编辑、连通性测试按钮、能力标签 Chip、默认模型星标 |

### 4.3 响应式策略

- 桌面端优先：1440px / 1600px / 1920px
- 最小适配宽度：1280px 可用，1024px 降级为可滚动布局
- 左右栏可折叠，中间主预览始终保留
- 高级设置可收起以适应小屏
- 平板端降为双栏（左侧折叠为抽屉）
- 移动端提供简化模式（仅对话与生成）

### 4.4 可访问性要求

- 所有图标按钮提供 `aria-label`
- 表单控件关联 `<label>` 或 `aria-label`
- 异步状态更新使用 `aria-live="polite"`
- 提供 skip-link 跳至主内容区
- 模式切换使用 `<button role="tab">` + `aria-selected`
- 视频播放器支持键盘操作
- 颜色不作为唯一状态表达方式
- 组件状态包含 Focus / Focus-visible
- 尊重 `prefers-reduced-motion`
- `<html>` 设置 `color-scheme: dark`
- `<meta name="theme-color">` 匹配页面背景
