# Agnes AI Studio 管理员指南

## 初始化管理员账户

### 方法1：使用命令行脚本（推荐）

在服务器目录下运行：

```bash
cd server
npm run create-admin
```

按照提示输入：
- 管理员邮箱
- 管理员密码
- 显示名称（可选）

### 方法2：手动更新数据库

如果已经有用户，可以直接更新该用户的角色：

1. 找到你的用户 ID（可以在注册后查看数据库）
2. 使用 SQLite 工具连接数据库：
   ```bash
   sqlite3 agnes.db
   ```
3. 执行 SQL 更新：
   ```sql
   UPDATE users SET role = 'superadmin' WHERE email = '你的邮箱@example.com';
   ```

## 管理员功能

### 1. 仪表板
- 查看平台总用户数
- 查看任务统计（成功、失败、运行中）
- 查看积分消费总额
- 查看今日新增用户和任务

### 2. 用户管理
- 查看所有用户列表
- 搜索用户（按邮箱或昵称）
- 筛选用户（按状态或角色）
- 查看用户详细信息
- 编辑用户信息：
  - 修改昵称
  - 修改角色（普通用户/管理员/超级管理员）
  - 修改会员等级
  - 调整积分
  - 启用/禁用账户
- 给用户充值或扣除积分
- 删除用户（超级管理员）

### 3. 任务管理
- 查看所有用户的任务
- 按状态筛选任务
- 按类型筛选任务
- 查看任务详情

## 角色说明

| 角色 | 权限 |
|------|------|
| `user` | 普通用户，只能使用平台功能 |
| `admin` | 管理员，可以访问管理后台，查看和管理用户 |
| `superadmin` | 超级管理员，拥有全部权限，可以删除用户 |

## 安全建议

1. **保护好管理员账户**
   - 使用强密码
   - 不要与他人共享账户
   - 定期更换密码

2. **数据库安全**
   - 定期备份数据库
   - 确保数据库文件权限正确（不可公开访问）
   - 将数据库文件放在非 Web 目录下

3. **日志监控**
   - 定期查看服务器日志
   - 关注异常的 API 调用
   - 监控失败的登录尝试

## 常见问题

### Q: 如何查看当前的所有用户？

A: 登录管理后台后，点击"用户管理"标签页即可查看所有用户。

### Q: 忘记了管理员密码怎么办？

A: 有两种方法：
1. 使用"忘记密码"功能重置（需要配置邮件）
2. 直接在数据库中更新密码：
   ```sql
   UPDATE users SET password_hash = '新的哈希值' WHERE email = '你的邮箱@example.com';
   ```
   （密码哈希可以使用 bcrypt 生成）

### Q: 如何把另一个用户升级为管理员？

A: 
1. 在用户管理中找到该用户
2. 点击"编辑用户"
3. 在角色下拉框中选择"管理员"或"超级管理员"
4. 保存更改

### Q: 管理员积分不够怎么办？

A: 超级管理员可以在用户详情页面给自己充值积分（充值金额可以是负数来扣除）。
